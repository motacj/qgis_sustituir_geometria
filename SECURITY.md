# Security policy

Please do not publish sensitive project data in an issue.

Report a suspected security problem privately to `atom.susej@gmail.com`, with
the affected version, reproduction steps, and impact. Ordinary bugs and feature
requests should be filed in the public
[issue tracker](https://github.com/motacj/qgis_sustituir_geometria/issues).

The plugin has no network features, external services, credential storage, or
automatic edit commits. Official QGIS uploads are additionally checked with
Bandit, detect-secrets, Flake8, and file analysis.
